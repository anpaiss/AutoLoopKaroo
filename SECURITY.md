# Security Policy

## Supported versions

Only the latest release is supported. Please update to the most recent version
before reporting an issue.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report them privately through GitHub's private vulnerability reporting:
open the **Security** tab of this repository and click **Report a vulnerability**.

You can expect an acknowledgement within a few days. Fixes are published as a
new release; the report is disclosed publicly only after a fix is available.

## Scope

This is a Hammerhead Karoo extension. It runs entirely on the device, does not
use the network and does not collect or transmit personal data. Reports about
the extension's own code (e.g. exported Android components, intent handling)
are in scope; issues in the Karoo OS or SDK should be reported to Hammerhead.
